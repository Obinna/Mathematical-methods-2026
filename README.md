# PhD Lectures on Mathematical Methods

This repository contains materials for a set of PhD lectures on **Mathematical Methods**, with a special focus on **computational tensor algebra using large language models (LLMs) and Mathematica**.

The course connects analytical methods used in mathematical physics with symbolic and tensor-computation tools. It introduces variational calculus, differential equations, tensor algebra, Mathematica, and the xAct suite, including xPand for cosmological perturbation theory. LLMs are used as learning and problem-solving aids throughout the course.

## Software setup

### 1. Install Mathematica

The University of Portsmouth (UoP) has a campus-wide licence with Wolfram Research. Use your **UoP email address** to access the [Wolfram site information and download page](https://www.wolfram.com/siteinfo/).

Installation instructions for different operating systems are available on that page and in Wolfram's [MathLM installation guide](https://reference.wolfram.com/language/tutorial/InstallingMathLM.html).

If you encounter problems with access or installation, contact ICG Computing at [icg-computing@port.ac.uk](mailto:icg-computing@port.ac.uk).

### 2. Install xAct

After installing Mathematica:

1. Download xAct from [xact.es](https://xact.es/).
2. Follow the [xAct installation instructions](https://xact.es/download/install).

xAct is a collection of Mathematica packages for symbolic tensor calculations.

### 3. Install xPand

xPand is used for cosmological perturbation theory. Download it from the [xPand project page](http://www2.iap.fr/users/pitrou/xpand.htm) and follow the [xPand installation notes](http://www2.iap.fr/users/pitrou/installation_xpand.txt).

## Using LLMs in the course

LLMs can help explain unfamiliar concepts, suggest ways to approach a derivation, and assist with Mathematica code. Treat their output as a starting point rather than an authority: check mathematical reasoning, tensor conventions, assumptions, and computed results against the lecture notes and independent calculations.

## Suggested preparation

1. Arrange access to Mathematica through the University of Portsmouth licence and install it.
2. Install xAct, then xPand, following their respective installation notes.
3. Open the relevant lecture notes and notebooks in Mathematica.
4. Bring questions about the mathematical methods, symbolic calculations, or software setup to the sessions.
